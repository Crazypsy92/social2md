# 磁盘与资源保护

## 默认阈值

| 项目 | 默认值 |
|---|---:|
| 暂停阈值 | 95% |
| 恢复阈值 | 90% |
| 最低剩余空间 | 1 GiB |
| 下载期间检查间隔 | 2 秒 |
| Douyin 元数据批量大小 | 30 个作品 |
| 下载并发 | 1 个作品任务 |
| 转录并发 | 1 个视频 |

## 监控范围

统一流水线监控项目工作区、输入媒体目录、Markdown 输出目录、状态目录、导出目录、系统临时目录和 Hugging Face 模型缓存目录。按设备号去重，避免同一文件系统重复统计。可用时同时检查 inode 使用率。

## 暂停和恢复

达到 95%、剩余空间低于 1 GiB、inode 达到暂停阈值，或预估临时空间不足时，停止启动新任务。下载期间按检查间隔轮询磁盘；触发保护时取消当前下载，只有确认无效的半成品视频才可清理，完整视频和 Markdown 保留。

恢复条件为所有受监控文件系统使用率低于 90%，且剩余空间满足最低保护值。程序退出后重新执行相同命令即可根据状态库恢复。

## 安全删除

视频只有在媒体有效、处理成功、Markdown 原子写入且内容校验通过、转录质量未触发复核后才允许删除。低置信度任务标记为 `REVIEW_REQUIRED` 并保留源视频。

文档转换永远保留源文档。ZIP 导出失败不得影响已完成的 Markdown 和任务状态。
