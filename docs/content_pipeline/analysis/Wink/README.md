## 观点分析边界

本批材料中频繁出现“女性都怎样”“男性都怎样”、关系必须由一方主导、用忽冷忽热制造吸引、通过沉默或不拒绝推断身体接触意愿等说法。分析稿保留讲者的原始主张，但不把这些说法包装成心理学事实或普遍规律。

重点区分：

1. 自我价值与对方是否回应；
2. 主动表达与控制、强迫；
3. 合理边界与情感冷漠；
4. 关系中的经济协商与单方面索取；
5. 个人经验、群体概括与有证据支持的结论；
6. 对方明确同意、沉默、犹豫和拒绝之间的区别。
