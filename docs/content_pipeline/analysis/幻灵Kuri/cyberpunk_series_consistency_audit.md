## 四、剧情与设定边界

| 易混淆项 | 统一后的边界 |
|---|---|
| 2013 年与 2023 年荒坂塔事件 | 2013 年是强尼营救奥特·坎宁安相关行动；2023 年是第四次公司战争期间的数据库突袭与核爆，不能混为同一次行动 |
| DataKrash 与 R.A.B.I.D.S. | DataKrash 是数据崩溃事件 / 相关代码体系；R.A.B.I.D.S. 是自我复制的 AI 攻击程序群，不能当作同一个名词 |
| Nomad Riots 与 Nomad March | 1996 年游牧民骚乱与 2010—2011 年游牧民长征是不同事件 |
| 第四次公司战争与统一战争 | 前者属于企业之间的全球冲突；后者是新美国试图重新整合自由州的国家战争，不是第五次公司战争 |
| Bakkers 与 Aldecaldos | Bakkers 是流浪者 V 的原生家族；阿德卡多是帕南所属的另一个流浪者家族 |
| Don't Fear the Reaper | 本体隐藏的单人突袭路线；成功后仍进入太阳或节制结局，不单独计作常规结局 |
| 《往日之影》四种 King 结局 | 权杖国王、宝剑国王、圣杯国王、钱币国王是四种主要人物结局 |
| 高塔（The Tower） | 《往日之影》解锁的本体新结局，不是第五种 King 结局 |
| 百灵鸟与 Engram | 百灵鸟是活着的网络黑客 / 情报人员；强尼的 Engram 是 Relic 中的数字人格构造体，二者机制不同 |
| 神经矩阵与 Relic | 神经矩阵是治疗装置，Relic 是承载人格构造体的芯片技术，不是同一种设备 |

## 六、需要继续保留的材料边界

1. **没有核听原视频音频。** 本轮以仓库中的原始转录、可访问的游戏设定资料和外部网页为依据；不能声称完成了逐句音频校对。
2. **桌游设定存在版本口径差异。** 《Cyberpunk 2013》《Cyberpunk 2020》《Cyberpunk RED》及《赛博朋克 2077》相关设定在部分年份、人物资料和事件统计上存在差异。正文保留了已知差异，不把单一版本写成无争议事实。
3. **非官方资料库只作交叉核对。** Fandom、社区档案和攻略资料不等同于 CD PROJEKT RED 官方设定；分析稿中已尽量标明来源性质。
4. **象征与人物动机属于解读。** 塔罗牌、诗歌意象、角色内心动机和未解释的蓝眼睛先生关联，不应写成开发者确认的唯一答案。
5. **章节排版暂时保留。** 本轮只修复术语、范围、来源和交叉一致性；专题文章的章节标题继续用于 GitHub / Obsidian 导航，没有强行改成单一正文或 Callout 版。
