# Cyberpunk 2077 观点分析稿

## 处理目标

将幻灵Kuri已归档的《赛博朋克 2077》相关转录材料，按照 Relationship Script Digest 文案 Skill v3.3.0 的“观点分析型”或“观点分析型（案例论证增强版）”整理为可独立阅读的文章。

本目录只保存二次分析稿，不承担 ASR 校订功能。

## 保留与对照规则

1. 原始转录保留在 docs/archives/bilibili/幻灵Kuri/，不覆盖、不删除、不改名。
2. 已有 docs/content_pipeline/raw/、corrected/、obsidian/、diffs/、candidates/ 产物保持原样；它们属于既有转录校订实验。
3. 新分析稿统一放在本目录，文件名使用英文 snake_case，正文使用中文。
4. 分析以原始转录表达的论点、事件和案例为依据；不把视频解读自动当成游戏官方设定。
5. 明显的 ASR 专名错误可按上下文统一为常见译名；不能唯一判断的名字、日期、数字和事件细节，放入“转录待核验”而不擅自补全。
6. 当任务明确要求外部校核时，使用 CD PROJEKT RED 官方中文资料、官方设定集译介和可追溯的设定资料交叉核对；把设定事实、视频观点和分析推论分开标注。
7. 每篇均包含文章思想、论证结构、正文展开、最终落点和事实边界；短篇可显式分为推理过程与完整正文，长篇可按主题章节展开。案例必须在正文展开，不能只出现在表格中。
