# 统一任务流水线

## 设计原则

项目不区分云端和本地处理入口。所有来源都进入同一套队列与安全规则，差异只存在于来源适配和处理器。

## 输入来源

| 来源 | 采集 / 输入 | 当前状态 |
|---|---|---|
| Douyin | F2 主页作品分页 | 已接入 |
| 已有视频目录 | 文件扫描 | 已接入 |
| 文档目录 | 文件扫描 + MarkItDown | 可选依赖 |
| Bilibili | 平台适配器 | 待接入 |
| Xiaohongshu 视频 | 平台适配器 | 待接入 |
| Xiaohongshu 图文 | 笔记与图片适配器 | 待接入 |

## 统一流程

```text
来源选择
  ↓
来源适配 / 文件扫描
  ↓
标准化任务标识（platform + content_id）
  ↓
SQLite 状态检查与断点恢复
  ↓
磁盘空间 / inode 预检
  ↓
单任务下载或读取
  ↓
媒体有效性检查
  ↓
ASR / 视频 OCR / 文档转换
  ↓
Markdown 原子写入
  ↓
内容与质量校验
  ├─ 失败 / 低置信度 → 保留源媒体，记录状态
  └─ 通过 → 标记 COMPLETED
                ↓
          按规则清理视频源文件
                ↓
          Markdown 检查点 ZIP
```

## 视频删除规则

只有以下条件全部满足才允许删除视频：

1. 源视频可被 ffprobe 读取且时长有效。
2. ASR / OCR 处理没有异常。
3. Markdown 已原子写入正式位置。
4. Markdown 含有非空识别内容。
5. ASR 质量指标没有触发低置信度复核。

失败、空转录、低置信度、异常中断的视频必须保留。用户可通过 `--keep-source` 禁止成功后删除。

文档转换与视频不同：只生成 Markdown，源文档始终保留。

## 任务状态

| 状态 | 含义 | 默认行为 |
|---|---|---|
| PENDING | 等待资源恢复或重试 | 下次运行继续 |
| DOWNLOADED | 已下载，待处理 | 继续处理 |
| PROCESSING | 处理中断或正在处理 | 重新运行恢复 |
| COMPLETED | 输出有效且质量通过 | 跳过 |
| REVIEW_REQUIRED | 低置信度或需人工复核 | 默认跳过，显式重试 |
| FAILED | 下载、处理或校验失败 | 下次运行重试 |
| SKIPPED | 当前来源不支持的项目 | 跳过 |

状态唯一键为 `platform + content_id`。旧版以 `aweme_id` 为主键的数据库会自动迁移为 `platform=douyin`，保留原有状态、路径和游标。

## 当前限制

- Douyin 是当前唯一已接入的平台下载适配器。
- 视频目录输入与 Douyin 共用视频处理、状态、存储保护和删除规则。
- 文档目录输入使用同一状态与存储保护机制，但永不删除源文档。
- Bilibili、小红书接入必须实现独立适配器，不得复用 Douyin API。
