## 口播转录

分享一下最近学习Fog电机控制的阶段性成果。机制小型无刷电机控制板，它能干什么呢？

理论上，它可以用于小型机器人的关节，或者是轮毂电机等等。但目前我积极没有搞机器人的项目。这款控制器暂时只用于板玩。下面我展示一下。我将通过电脑界面设定工作模式与对应参数。速度模式，可以单纯地转，按指定速度转。位置模式，可以指定位置，跟随角度。

也可以设定为极轮模式，转起来咔哒咔哒的板玩。

可以设定主力模式，还能调节不同的主力大小，板玩。设定限位模式，感受档外的修改。

我最喜欢的是弹簧加主力模式，可以通过界面调试参数。体现出不同的动态响应。好玩。

硬件方面，我参考了SimpleFook Mini的硬件方案。选择了DVR8313作为驱动IC，驱动一路电机。电机的两厢有采样电阻，并通过运算放大器放大电压信号。供STM32的AD模块采集。控制板的背面，有一片MT6701尺编码器。

对外提供串口和CAN通信接口，方便调试与配置参数。软件方面，我大致浏览了SimpleFook。并且购买了灯哥开源的控制器，把它的代码整体学习和运行了一遍。但我实际使用下来，不知道怎么在Arduino上把性能最大化炸出来。

比如配置TMA提高采集和通信效率。相比来说，我对STM32更熟悉一些，因此我切换了MQ型号。并且在理解SimpleFook和灯哥开源的代码基础上。完全在我自己的板卡上。在调试各个控制环路和数学变换的过程中。使用魔法上位机进行数据和实话，方便诊断分析。

单功能各个软件开发完毕后，我还写了一个简单的QT上位机。通过CAN消息配置功能和参数，方便把玩。之后，我考虑使用这款控制器制作多关节的机器人。比如很多人做过了轮腿机器人，或者是主的机器人。我的另一个极搭效果器的新版本板卡。

由于春节期间工厂要加钱才开工，我就选择了默默等待。等板卡一到，效果器开发版就可以继续推进。大家敬请期待。
