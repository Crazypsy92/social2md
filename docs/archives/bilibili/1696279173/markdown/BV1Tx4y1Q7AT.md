如果你喜欢弹吉他，又有电子或者软件开发的技能，你是否考虑过自己设计其他的数据效果器呢？又或者你喜欢吉他，同时也想学习嵌入式相关的技术，想做自己的嵌入式项目吗？现在，你有福了。厂长一号数据效果器开发平台重磅推出，只要你有一丢丢的C语言记住，谣厂长带你玩转数据综合效果器，让你自己编程做出最适合自己需求的效果器。

外观与硬件，精心设计的外观图案，硬核机外也有艺术感，两种版本可选，铝格或打印塑料壳，标准的效果器旋钮和旋钮帽，手感绝佳，活技术彩丁，丰富交互扩展可能性。数据JIME，演出，绝对没问题，1.8吋屏幕，小小精致，提供无穷扩展可能性，有耳机输出口，学生党恋情服务员，程序下载口，无需拆格便能更新固件，开发者期间可以分享各级开发的固件。

核心开发板搭载STM32H7处理器，算力强大，资源丰富。

如果你购买我的开发板套件，我将寄这样一个箱子给你，一起来看看。看看这里有什么，一个配套电源，一个Slink工具，一个数据线，完全装备好的效果器。你拿到这个箱子后，不需要你购买任何其他的设备，到时候就可以跟着我的视频教程玩起来了。

一个单纯的开发平台是没有生命力的，因此我会配套录制大量的视频课程内容，方便大家跟着一步步做，解锁各种玩法，了解各种知识。1.开发环境编，包含两个章节。基本内容，视频已经发布。1.开发平台硬件与软件架构说明。2.开发环境搭建，软件的编译与杀战。

如果你跟着视频搭建环境并测试，应该可以在一个小时内完成。完成这一编后，如果你有C语言基础和音频处理基础，你就可以略过其他内容开始你自己的开发之路了。而音效处理编目前还没有上传，但我会持续更新，内容占我重点。随着我自己。玩得更多，我会逐渐更新内容，只要我自己还在玩，内容更新就不会断。

更新频率大概一周一到两篇，目前想到以以下内容可以更新。1.地同高通绿波的原理与开发实践。2.货债。3.产业。4.玩音5delay。6.时针法制。8.夜的含义与音箱的I2复刻。9.混响。10.相位。11.相面。还有音高改变等等等等。

音效编的。每一个个教程，都会提供独立的代码历程，烧录运营一个历程，开发平台都可以变成一个独立的档框效果，在学习了多个模块的基础上，开发者可以自由组合，利用踩钉旋钮，组成多级串联的效果链。3.硬件与驱动编。如果你已经掌握了算法软件技能，想进一步学习这一款开发平台的硬件如何设计出来，如何编写驱动程序让效果器能够正常工作。

那这一篇的内容非常适合你。1.原理读拆解与电路大致拆解。2.Add DMA，完成旋钮电压采集。3.Speed通信与屏幕的显示。4.I2C通信与音频接口配置。5.I2S通信与音频信号通路。6.音频编解码芯片功能拆解。7.用犹太史重构裸机架构。
