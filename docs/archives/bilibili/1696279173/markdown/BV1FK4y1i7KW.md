这几天，计划版效果器终于满足了，积极地使用要求，现在的格子是3D打印的，金属会更有技感，彩钉技感还行，但是灯光还要改善，用我常用的音箱给大家测试，请诸日常练习用情。

我就积极弹给大家听听效果，先用调音表调个音，第一个是boost效果，用于控制电频。方便演就时快速调整音量，弹节就是无动场，要稍微的踩一下，瞬间有力，混上可以调开视频，空间大小，衰减的履历，空间大点的感觉，小空间感觉，一般喜欢调到适中，一个厚的感觉，七个旋钮可以微调衰减的空间感。
