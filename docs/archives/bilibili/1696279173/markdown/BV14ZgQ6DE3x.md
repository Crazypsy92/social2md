# 学自动化到底能干啥？我用毕设把课本知识飞了起来

## 来源

https://www.bilibili.com/video/BV14ZgQ6DE3x

作者：饶厂长讲传统工科求职

## 原文案

个人观点，希望帮到有需要的小伙伴

## 口播转录

很多同学在私信评论里面问我，说现在大三大四除了竞赛还能做点啥，有没有什么项目是值得做的，怎么做？今天我分享一个实际案例吧，分享一个我2014年做的毕业设计项目，看看能不能给大家一些启发。2014年我读大四，出于兴趣呢，我花了大概半年时间，从画电路板，写驱动，调算法，从现成的机架开始，自己做了一架能飞的丝绸飞行器。

由于我做的这个目的是锻炼自己的技能，所以没有用现成的飞控去改，而是从硬件到电路到控制逻辑都是一点一点自己弄。现在回头看，这可能算是我大学四年最有成就感的事情之一。今天分享一下这个项目，希望能给正在经历这个阶段的朋友们一些启发，一些鼓励。

首先分享一下整个飞机的硬件部分。机架用了淘宝上买的玩具四轴探索机架，整70多颗。我后续做的所有工作其实就是把它的主板拆下来，然后换上我自己的。那为什么机架和螺旋桨不自己弄呢？因为当时我也不懂机械和启动，而且3D打印也不普及，想加工这样的一个东西也是比较困难，所以我也望而却步。

硬件的主控选的是FaceCard的一款单片机，当时因为我们做智能车比赛，常用这款芯片，比较熟悉。姿态传感器用的是MPU6050，也是非常常见的一款芯片吧。整个控制板我自己画PCB。自己焊模块，焊芯片，像电机驱动啊，这些外围电路都是自己搭的原理图。

顺便提一句，E版的板子太重了，模块太多，飞不起来，后来逐步迭代精简，有的版本有bug也不能用，前前后后做了8个版本，所以才叫ZDY-8。在简单讲讲里面的软件，主要是两部分，一部分是姿态检测，一部分是姿态控制。姿态检测说白了就是飞机怎么知道自己角度偏多少，偏的速度是多少。

我为了学习呢，尝试了两种方法，户谷滤波和卡尔曼滤波，虽然现在看起来回头看很简单，但是当时想玩好也花了非常多的精力。姿态控制说白了就是让飞行器能稳定的飞行，能把角度得控制住，能遥控俯仰角，偏航角，混转角。也是为了学习，尝试了两种方法，一种是PID，一种是滑膜控制。

为了参数准确，控制其设计之前，我还对系统进行了简单的研究。

做了一些参数的仿真才上真机去验证。经过了多种算法的尝试学习吧，我也逐渐了解，工程上也不是说越高级的算法就越好，合适的才是最重要的。分享一个比较土的细节，当年没有买专业的测力的设备，测电机的生力我就是拿厨房秤去称的。给电机通不同占风笔的皮团栏目，看看能拉起多少重量，一点点拟合成曲线。

当年调试也挺狼狈的。不敢让飞机直接飞，就用绳子挂着机架，俯仰脚，滚转脚，单独调试。炸机是常试，拆了焊焊了拆，来来回回也好多次。当然也有遗憾，本来计划是更加宏大的，想和同学合作做一个双目视觉的自主悬停。让飞机不用遥控器也能自主悬停在办公，但是能力不够，时间也不够。

同学双目的部分其实做到能检测三维的位置，但是我没有能让实机联动起来。即便有遗憾，做完这份毕业设计我还是有非常大的收获。让我知道人一旦稍微专注一点，连续的行动起来，能有多大潜力。我想和现在正在迷茫的同学说，当你真的从最基础的工作开始，一步一步把一堆资料和设计。

变成实实在在的物品，你就会明白自己是可以摆脱迷茫，摆脱无力感的。那如果你现在还在学校，有做项目的机会。那请你行动起来，认认真真做一个完整的项目。这比你技点多考几分重要得多。这不光积累你的工程能力，更多的是在修炼自己。你练好内功，不内耗不纠结，你才有可能获得你理想的生活。

你在项目里练的查资料，排错，工程思维，这才是你离开学校后唯一能依靠的本事。那你们当年毕业设计做的是什么？评论区聊聊，关注我。饶厂长带你看清。
