## 口播转录

你们有没有发现，如果你在学校里做科创类的竞赛，比如电子设计大赛，RoboMaster，还有什么智能车比赛，如果你参赛的时候和竞争对手，其他的学校，包括你自己的校内的同学聊天，你会发现，有的来自机械专业，有的来自电子专业，有的来自自动化专业，这三个方向专业的人在竞赛里是扎堆出现。

如果你在非纯软件的研发岗工作，你问一下你的同事，大概就能凑齐机械自动化电子三个方向的人。如果你去任何一个生产车间，你问一下技术员，你会发现调机器的，做工装的，搞自动化的，还是这些专业的人。为什么是，难道是大家很有缘分吗？当然不是，这背后有几个非常深刻的原因。

第一个原因是产品的本质决定的。一个能在现实世界中运动交互做工的这样一个产品，它本质上是三个核心组成，结构，它的骨架，你存在的物理实体，第二个电子。你有系统的供电，通信，传感器，等等。控制系统，你的产品的大脑，发出控制指令，让产品按照预期去运动，这三个系统缺一不可。

没有结构，电子和控制就没有附着的地方。没有电子，结构就是一堆废铁，控制也是空中楼阁。如果没有控制，那结构和电子就是一个模型，它也动不了。所以任何一家做硬件产品的公司，不管是机器人，无人机，3D打印机，还是手机。手表，电动牙刷，甚至几块钱的玩具，都必须同时拥有这三个领域的工程师。

这不是公司的选择，是物理规律的限制。

第二个原因，这三个专业的底层能力是高度融合的。除了产品形态的需求，这三个专业本科培养体系本身就高度重合。大一、大二的公共基础课，还有专业基础课，几乎一模一样。高等数学，大学物理，现行代数，工程制度。这都是一样的。大三的专业课也有很多一部分是重叠。

机械的也学单面积，也学自动控制原理。

自动化和电子都得学电路原理，磨电输电，还有什么传感器原理。真正有差异的那点专业课，就这么几门，而且涉猎也很浅。但凡你想做一个完整的，能跑动动的项目，你就必须要自己把另外两个专业的内容补齐。比如说你是学机械的。你想做一个小型的。

你也得能搞电路板，你自己也得学习怎么写这个控制的代码。如果你是个学电子的，你想搞一个智能小车，很简单的项目，那你必须也自己搞定机械的这个部分，做3D打印也好，或者说机架工也好。一个学自动化，你想做一个机械臂，那你必须要自学结构设计，自己学硬件的电路相关的部分。

在学校里做项目是这样，公司做产品也是这样，你不可能把一个问题切割得干干净净。

如果出现一个问题，你说这是机械的问题，这是纯电子的问题，这是纯控制的问题，大部分有价值的问题都是跨专业的问题。很多同学看到这里会问，那我学了一个专业算什么，看起来大家都差不多，我好像没有什么优势，好像我能干的别人也能干，恰恰相反。

如果你一旦接受了机械电子自动化，大家都是同进同退的这样一个设定，你会发现路就会宽了。我给你两个非常具体的建议。你如果靠着做，你一定会比同龄人成长得更快，第一个建议，彻底打破专业的边界感，你不管是读书的时候，竞赛的时候，工作的时候，千万不要有说，这个是别人的事情，我不用关心这种想法，假如说你是机械工程师，不要只画图，你去看看电子工程师是怎么工作的，你怎么去跟他写作，然后你跟控制工程师看看他们有什么样的需求，什么样的建议，了解一下你的结构对其他方面的影响。

如果你是电子工程师，同理。你不要只画板，对吧，你看看控制工程师是怎么做的，你去看看这个机械是怎么做的，同理，你要是做自动化的，做控制的，你不要也是只写代码，只做你的那些参数缝制，你得去了解机械是怎么设计的，去看看电子工程师设计的硬件，对你有什么影响，对吧，你不了解系统，你是不可能做控制的，我见过太多的工程师，工作了三五年，只做自己那一小块。

机械工程师。

我都不知道这个电机的扭矩怎么计算，电机的做工怎么评估，电子工程师也不知道你这个系统是怎么控制起来的，你是用的PID还是什么MPC乱七八糟的，不了解，控制工程师也不知道，是吧，我这个工件是怎么加工出来，你不同的材料对我的控制是有什么影响，模态上有什么改变，都不了解，那如果你是这样的状态，你只能当个螺丝钉，永远在低水平徘徊。

了解相邻知识的人，很快就会脱颖而出，因为他们能解决跨专业的问题，而且在一个系统里，所有的复杂的有价值的问题都是跨专业问题，这种能力是你未来从工程师健身到架构师，项目经理，甚至说你自己开一家公司，这都是必备基础，一个不懂电子和控制的机械工程师，你不可能成为一个优秀的产品负责人，第二个建议，有意识的培养全局思考的能力，当你掌握思考的能力，你不可能成为一个优秀的产品负责人，第二个建议，有意识的培养全局。

三个专业的基础知识后，你就可以脱离具体的技能，站在全局的角度去思考问题，你不用想着去这个结构怎么画，这个电路怎么设计，这个代码怎么写，你可以开始思考这个产品解决了用户什么问题，我们的竞争对手是怎么做的，这个东西的设计成本是多少，能不能再降低，这个产品好不好生产，好不好装配，好不好维修，这个产品的生命周期是多长，未来的升级方向是什么，这些就是全局思考的能力。

不谋全局者，不足谋抑郁，当你站在整个产品的角度思考问题的时候，你就不再是一个普通的执行者了，你已经具备了一个决策者的基本素质。以前很多人把三个专业分得特别清楚，井水不犯河水，但那个是简单产品的时代，非标自动化的时代，但是未来真正值钱的是把这些专业能力打通的符合性工程师。

而且现在有AI的存在，任何一个小白，如果你会问问题，你都可以得到答案。你都可以得到在十年前只有专业人士才能给到你的回答，你现在不需要成为每个领域的专家，但是你必须每个领域都懂一点，并且能把它整合起来，至少你得学会怎么问出正确的问题。
