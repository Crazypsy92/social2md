本视频是技智综合效果器配套课程的第一篇，将介绍技智数据效果器的软件硬件架构。在开始前，我先简单的说一下模拟单块效果器和数据效果器的区别。对于电吉他来说，琴弦切割拾音器的起感线，将声波转换为变化的电压。模拟效果器工作的过程，是将电压作为输入。

通过运算放大器、扇机管、电容电阻等模拟电路器件组成的电路，对电压信号进行改变的过程。这个过程是没有间隔的。而数据效果器工作的过程，是将电压通过A、DC产压，变成数据信号，再将数据信号放到计算器中进行数学运算，再通过DAC进行输出的过程。

这个过程中，ADC和DAC都是有间隔且有分辨率的信号。我们常说的说明24K、48K、44.1K采样率。说的就是ADDA的采样频率，表示每秒钟能采集多少个点。点越密，还原度越高，能表现的频率越宽。而16倍、24倍等，说的是采样的分辨率，表示能分辨出多细微的变化。

极小台阶的最小差值。中上，模拟效果器通过器件特性，设计电路改变音声。而数据效果器通过采样与计算改变音声。我们已经说过了数据效果器的工作流程，即A、BC采样、计算和DSE输出。在遥想掌机制的效果器开发板上，ADC和DAC有一块编解码芯片完整。

这块编解码芯片通过高速的I2S数据通信接口，与高性能的STM32H7链接。为了使芯片工作，整块板卡需要供电。为了与乐器和音箱连接，需要外接音频接口。为了方便的改变音质阐述。切换功能，需要让STM32H7能独取旋钮与彩钉的电压。

为了延续交互，需要一个小屏幕。最后，为了风向格子后也能下载情绪或者干部型。增加了串口通信与自动下载电路。以上就是硬件的大致架构与功能。整体软件处理流程与硬件设计严密配合。

一一对应。在驱动层面，有专门的模块负责旋钮与彩钉状态的采集。采集的结果集齐一些二进制的数据。与效果参数无关。由适配层的模块将这些数据转换成有含义的阐述。并供上层调用。屏幕也有驱动层的模块对外提供基础的API接口。由业务层直接调用。

英明模块方面，驱动层R2C对上提供通信接口。英明模块配置模块调用R2C。

完成参数与功能配置。最关键的音频处理流程。由IOS的中段提供。中段为提醒程序一批数据已经就绪，可以处理。处理完毕后，IOS会从指定的地址取走处理后的数据。通过IOS发送给音频模块，最终推给音响。所有的音效，基本都在这个流程中实现。
