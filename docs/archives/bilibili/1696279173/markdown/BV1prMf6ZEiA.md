## 原文案

个人观点，希望帮到有需要的小伙伴

## 口播转录

最近有粉丝找我咨询，说的特别戳人的，就说，厂长，我刚毕业就务职一家公司做实施委工的事，我现在还在培训期，说是培训，其实就是给一堆文档自己看，没人带也没人教我，每天上班就是摸鱼，我心慌，感觉啥也学不到，再待下去人感觉都待废了，想着我辞了又不知道自己能干啥，能去哪，也怕辞了找不到工作，每天都内耗，特别痛苦，很多刚毕业的同学入职前都以为公司会像学校一样，有特别系统的培训，有师傅手把手带教我。

一步步带你成长，结果进去了你发现所谓培训就是自己看文档，看视频，所谓带教可能就是遇到问题可以去问，偶尔有讲解也是讲，参数怎么调，机器怎么用，界面怎么用，线怎么连，可能有一些案例，但是你总感觉还没学到什么东西，为什么你觉得学不到东西，到底公司有问题还是自己有问题，到底应该怎么办，全是实在话，刚入职的新人一定要看吧，很多人觉得学不到东西，第一反应就是公司垃圾，培训不行，但绝大多数的实施岗本来就不是靠公司培训。

学东西呢，你觉得学不到往往不是真的没东西，想吧，一个公司它能生产出来一种设备或者某种产品，然后卖给客户，产生价值，你觉得这家公司没东西，我觉得大概率不是它没东西，你觉得学不到东西主要是有以下几个原因，第一个原因是培训期是打击盒，你看起来像没用，所有的公司的实施培训岗，你都得看产品文档吧，得熟悉产品功能，你看看其他项目案例，这些东西你看起来好像学的是没什么用，好像跟技术有关。

但是你是你后面的工作。的基础，如果你连产品什么功能能解决什么问题都不知道，那你去的客户现场呢，那才真没用，你很多人耐不住性子，看了两周这个资料就觉得学不到东西，其实你还没上到，第二个原因是实施岗的核心能力，它不是上课学的，它是项目跑出来，那这是比较关键的一点，实施工程师核心能力是什么，不是你知道某某信息某某知识，是你到了客户现场能定位问题，解决不少，你面对客户需求，你能判断可行性，你能沟通，能把这个东西落地。

如果项目出了意外，你能够协调公司的资源，能为客户减少损失，能为公司减少损失，那这些能力文档里是行不了的，只能靠你跟着项目跑的过程中踩一次坑，解决一次问题，你真的学会一次，你现在才在培训期，你还没真正接触，那你当然会觉得比较空白，比较虚弱，你不是没东西学，你还没开始，所以当你觉得还没学好就去干活的时候，就不要怕，这就是学习的机会，该怕的是公司，你大胆学大胆量，拿不准的就问，你只要不违法乱纪。

违规乱搞，真出了娄子那是公司胆子，不是你胆子，还有第三个原因就是公司可能真的很狠，可能有些公司真的不行，他既没有培训也没有老师，有可能这个组是你是唯一的人，公司也没有什么像样的项目，你进来就是打杂，你现在与未来可见都没有成长机会，这种情况可能确实不应该耗着，但实际上这种情况不太多，毕竟公司你招聘的前提是有业务困难，要不然你招人来干什么，所以你觉得学不到东西的时候，别冲动说我马上要落资了。

你判断一下这家公司。先判断一下这家公司到底值不值得留，判断标准一，能不能接触到真实的项目和用户，第二个标准是公司所在的这个赛道和他做的产品到底有没有前景，那如果你判断完你觉得公司是值得留下的，那你就应该调整一下思路，把被动等待学习转换成你主动学习，怎么学，第一个，你把看文档或者看资料变成带着问题找答案，你不要被动的说，很多人看着文档就是。

你顺着读一遍，这不可能有用，正确的做法是你先自己先问问题，建立这个问题的框架，建立一些前置的问题，比如说，你在看文档之前，你先问自己，这产品给什么客户用的，用在什么场景或者流程下，你解决客户什么痛点，有哪些核心功能，哪些关键指标，什么参数可能是要灵活配置的，这个东西怎么部署，怎么和用户的系统联动，你带着这些问题去看文档，把自己当客户，把你自己假装成是一个客户的状态。

审视这个产品说明书，你是怎么用的，我应该，我为什么要买你的产品，或者说你这个产品放在我这儿，我会怎么用，我需要关注哪些点，你带着用户的视角，带着这些问题去看文档，你把文档当成答案吧，而不是教科书，你看完一遍，以后你能把这些问题说明白，那这个文档你没白看，如果文档解答不了，你就赶紧问，然后记录下来，第二个方法就是说，跟着老人工跑项目，把你的打杂变成学习的机会，如果你能去客户现场，你就能去则去，就是新人最好的机会。

但是去之前你要提前了解，这项目做什么，客户有什么问题，客户需求点是什么，去的时候仔细看仔细听，你看老人工是怎么做的，到底怎么排查问题，怎么解决冲突，回来之后稍微复排一下，记录一下，如果你有十个五个这样的项目复排，你应该半年内就可以跨越成一个老手，那么假如说你判断了公司的现状和你自己的状态，你决定走，那你千万不要裸辞。

如果你是第一份工作，你裸辞了。并且你在找工作。的时候说你是因为学不到东西裸辞。你放心。你肯定找不到工作。你会发现你头减率是一身大汗。因为你没有什么拿得出手的经验。你面试的时候。人家问你为什么裸辞。你说学不到东西。只会显得你很浮躁。

抗压能力很差。然后你越找不到工作。越焦虑。最后随便找一个更差。又踩一次坑。你们有没有过入之后就觉得学不到东西这种经历。最后是怎么走出来的。评论区调量。给新人一点参考。如果你不知道自己现在是该留还是该走。或者想规划一下具体的转导路线。
