# 想成为硬件工程师，大学里该学哪些课

## 口播转录

大家好，我是硬件何工。

上期聊了我大学是怎么入门硬件的。然后后台也有同学问。他说何工，我想做硬件。大学到底该学哪些课？哪些课程重要？哪些课程可以水？今天不讲虚的，就讲讲我当年走过的路。哪些课程没学好后来后悔的？哪些课程我当年觉得没用。后来工作才发现真相？

如果你现在大二正在迷茫。这期就是讲给你听的。首先，先说说大一的课。高数，线性代数，大学物理。还有各种公共课程。说实话，这些课。不管是在学校做项目。还是工作以后。我基本上没有用上过。我不知道其他人什么感觉。反正我个人觉得完全用不上。

你可能会说，高数不是基础吗？线代不是工具吗？对，但是对于做硬件来说。你真正用到的数学。在磨点、数电、信号系统里面。都会重新教你一遍。大一学的。高数、线代。更多是为了考试。不是为了做硬件。当然，不是让你别学。该过的考试还是要过。

该拿的学分还是要拿的。但你不用因为大一学不懂高数。就觉得自己不适合做硬件。大一就是一个过渡企业。刚上大学。谁不想放松一下。迷茫是很正常的。但是大二就不一样了。大二才是真正的分水点。

大二你开始上真正跟专业相关的课了。我本科读的是电子信息工程。回头看。大二这一年修的课。是我整个大学最重要、。最实用。也是最基础的课。有哪些呢？磨电、数电、。信号系统、。电视场与微博、。计算机组成原理、。通信原理。这些课。

我全都用上了。不是好像用上了。是真的用上了。即便后来工作。我的工位上依旧放着这些书。已被我随之翻看。磨电是理解电路的基础。不懂磨电。你连一个运放电路都看不懂。不懂数电。去门都分析不了。信号与系统。是理解信号完整性、。电源完整性的前提。

等你后面做高速信号、。EMC、。电源设计。根儿都在这里。电视场与微博。不得不说。这门课是真的难。我同学考研。考电视场。专业课是要带计算器上考场的。但它是理解EMI、。EMC、。天线和传输线的基础。然后就是计算机组成原理。

这是一门概念性的课。它是让你。理解CPU总线存储怎么工作的。这对于你后面做SO设计。做系统框架。是非常有用的。通信原理。通信原理是帮你理解编码、。调制、传输、。做接口设计、。通信协议。离不开它。还有配套的实验课。电路分析实验。

锚电输电的上级时潮。这些实验课。现在想想。真是太有用了。如果当初能认真学好。对于未来工作可以打下扎实的基础。当然这一年修的课。没有一个是白修的。简直就是大学的精华首代。这些课。不是对所有人都一样有用。取决于你毕业后做什么。

如果你毕业搞纯软件。那这些课大概就用不上。磨电、。塑电、。线路系统。你可能一辈子都不会再碰了。唯一能用上的可能就是C语言。其他的考完基本都还给老师的。但如果你做硬件。或者做线路式软件开发。那这些课基本上都能用上。你调一个运放电路。

磨电姿势在起作用。你分析一个时序问题。塑电姿势在起作用。你排查信号完整性问题。信号与系统在起作用。做一个通信接口。通信原理的姿势在起作用。所以这些课的价值相对的。关键是看你走哪条路。但如果你还没有想好走哪条路。我建议你先把这些课程学好。

等于给自己留了很多选择。学好了。以后想转硬件底子还在。没学好以后想转。你就得从头补。现在很多人。想转行做硬件。第一反应就是报个培训班。我的观点不太一样。如果你已经毕业了。工作了。现在想转行做硬件。把电子信息专业大二那几门课的书。

拿出来啃一遍。

比报培训班强多了。为什么？因为培训班往往是竖成的。它教你怎么画板子。怎么用工具。怎么应付面试。而这些东西。你工作中几个月。甚至几个星期就能学会。而磨电。塑电。信号与系统这些课。教的是底层逻辑。为什么运放要这么急。为什么信号会反射。

为什么电源会震荡。这些才是决定你能走多远的关键。培训班不会教这些。但教科书会。你可能会说。书太难啃了。看不进去。对，确实难。但你想转行哪有不难的。与其花几千上万块钱。报班学个皮毛。不如花几个月。把这几本书啃下来。啃完了。

你的底子比报培训班出来的要扎实得多。不是说培训班完全没用。但是真想在硬件这个行业走得远。底层知识只能靠自己啃。到了大三。课程就更专业了。我当时修了单边机原理及应用。EDA技术与Virolog语言。还有通信电子电路。这些课比大二又上了一个台阶。

单边机能让你真正动手写代码。控制硬件。EDA和Virolog让你接触数字电路设计。接触IP戒。通信电子电路让你理解高频电路。和射频。前端。

这些课包括对应的实验。如果你能学好。拿到不错的成绩。那你基本上已经是一个硬件高手了。这不是我吹牛。是工作后回头看才明白的道理。现在回头看。我觉得大学课程设计的真的好合理。大一你刚来大学。心还没有收回来。爱玩。迷茫。正好大学给你安排的课程也是无关紧要的公共课。

高数现代物理。难是难。但跟专业方向关系不大。到了大二。当你开始真正走向正轨的时候。来的课真的都是货真价实的干课。磨电。竖电。线路系统一门比一门硬。大三以后基本就没有课了。要么工作实习。要么准备考研。

一切都是那么顺利成长。大一让你放松。大二让你上强度。大三让你自由选择。这个节奏设计的真的很好。我甚至觉得大学四年的学费都是给大二教的。可惜我当年没有完全看懂这个节奏。大二还有。一个隐形的资源。很多人没有注意到。教你课的这些老师。

很多都是带研究生的。这意味着他们手里有实验室。有项目。有资源。

你上课别只是坐在下面听。课后多去问问问题。聊你感兴趣的方向。聊着聊着。你可能就能进到他们的实验室。帮他们的研究生分担一些小任务。甚至参与真正的项目。我的研究生导师。就是我上大二课程时认识接触的。当时也就是课后。我多问了几句。

多聊了几次。后来就慢慢进了他的实验室。再后来研究生就顺理成章跟了他。

这件事情对我后面的影响很大。进了实验室。你就不只是在上课。而是在真正的做东西。有老师带。有研究生学长带。比你自己瞎摸手快得多了。别的学校我不清楚。反正我读书的航电。老师真的很喜欢主动的学生。你主动问他们问题。他们愿意回答。

你主动提出想进实验室。他们愿意给你机会。你主动想帮忙。他们愿意带你。工作以后才发现职场上也是一样。领导也喜欢主动的同事。说白了。主动的孩子有奶吃。很多时候只要你主动。就有意外的资源到来。你不主动资源也不会找上门。所以如果你现在在大二。

我强烈建议你。上课多跟老师互动。课后主动找他们聊。不要觉得不好意思。老师其实很喜欢。主动的学生。你不需要多聪明。你只需要比别人多走一小步。然后说到大二。

我觉得大二是参加各种学科竞赛的最佳时机。

大一你没有基础。啥也不会。参加竞赛就是打酱油。一轮游。我自己就是活生生的例子。大一那年我有幸参加了省电赛。但是没有拿到奖。当时我还不知道差在哪里。后来才明白。是有些课我根本还没有修到。磨电没学。数电没学。线耳系统没学。你拿什么跟人家比。

你光靠满腔热血和照猫画虎完全走不远。到了大二。课修了。基础有了。再参加电赛。完全不一样。德行应手很多。

大一参赛是懵的。大二参赛是心里有底的。大三你开始忙实习。忙考研。就没有时间了。所以大二基础行职了。直接就上。

我记得大二有电赛。智能车ACM。反正有很多比赛。我当时就是大二参加的电赛。虽然只拿了三个。但那段经历。让我真正把课本上的东西用起来了。而且大二也是很多人大学生涯的分水岭。很多人大二学得好。拿到大奖。大三不管是考研还是找工作。

都会顺风顺水。大二这一年你怎么过。很大程度上决定了你后面两年会怎么走。说到比赛。补充一个很现实的点。大学里很多人认为只要成绩好就行了。拿个高级点。拿个一定的奖励。奖励金稳稳的。但到了大二大三你会发现。只成绩好不参加比赛的同学。

在奖学金这块会很懵。为什么？因为大二大三的奖学金。很多时候都被比赛拿奖的同学拿跑了。你记点4.0。他记点3.7。但他拿了电赛一等奖。综合测评一算。他排在你前面。你说你委屈不委屈？委屈。但是规则就是这样。更关键的是。比赛拿了大奖。

后面是一连串滚动叠加的收益。你拿了一等奖。可以评国家奖学金。拿了国家奖学金。可以评十家大学生。拿了十家大学生。后面各种荣誉。各种机会都会向你倾斜。他不是线性的。他是滚雪球式的。一个奖可以撬动一堆资源。我相信一定有过来人。

懂得这个道理。如果你现在大二成绩还不错。还没有参加过任何比赛。我劝你赶紧去参加一个。不是为了功利。而是因为在这个规则下。比赛是你投入铲除比。最高的一件事情。好了，总结一下。如果你现在大二。正在迷茫。我给你四条建议。第一。

磨电塑电信号系统。一定要学好。这几门课是你做硬件的底子。学好了。后面什么都好说。学不好。后面什么都难。第二，实验课别摸鱼。电路分析实验。磨电塑电实验。这些才是真正让你动手实验的地方。别只为了交报告而做实验。真正动手做一遍。

比看十遍书都管用。第三。主动接触老师。争取进实验室。第四。大二一定要参加一次竞赛。不管什么竞赛。一定要参加一个。参加比赛的回报收益。远远比你拿到高级点的回报收益要大得多。一个工作多年后过来人的忠告。大二。真的是你大学四年最值钱的一年。

千万别浪费了。我甚至觉得大学四年的学费。都是给大二缴的。好了。这一期。就到这里。下一期。咱们聊点更具体的。入门硬件。到底该从哪下手。先学什么。后学什么。我是硬件和工。一个还在跟硬件死磕的工程师。关注我。下期。我们再见。
