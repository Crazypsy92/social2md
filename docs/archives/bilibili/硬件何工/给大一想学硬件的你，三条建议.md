# 给大一想学硬件的你，三条建议

## 来源

https://www.bilibili.com/video/BV1t2Wa6eEQn

作者：硬件何工

## 口播转录

大家好，我是硬件何工。这段时间后台私信问的最多的一个问题就是何工我想做硬件，但是不知道怎么开始。这个问题我太熟了，因为当时我也是这么过来的。

今天咱们不讲技术，也不讲电路，就讲讲我自己是怎么入门硬件的。讲一个普通学生从啥也不懂到慢慢摸出门道的过程。

如果你现在也是大一或者刚刚接触硬件，觉得很迷茫，希望我的故事能给你一点点的参考。2013年我刚上大学，专业是电子信息工程。

大一第一学习一般不都是学高速、现代、C语言、电路分析这些吗？然后课本上的东西基本上学完就忘了，真的。我现在回头看那些东西，那时候学的什么基尔火夫定律、戴威南定理，当时的确是懂的，但是考完试基本都还给老师了。

而且大一上学期的时候，社团活动特别多。学生会、团委、各种招勤，今天这个会、明天那个活动，大部分时间都花在社团活动和社交上面了，听起来挺忙的，但其实内心是空的，因为你不知道忙这些到底是为了什么。反正整个人就是挺迷茫的，不知道学这些有什么用，也不知道后面要干啥。

如果你现在也是这个状态，相信我，这很正常。因为大部分的工科生，大一都是这么过来的。区别可能在于有些人迷茫迷茫就习惯了，有些人迷茫着迷茫着就开始找事做了。然后大一的一个转折点就是社团招勤。我去面试了那个无形电爱护者协会，无形电爱护者协会就是电子学院的科协。

说白了就是一群喜欢折腾电子的人聚在一起，焊满着携带码，做项目，然后也可以一起参加比赛。我报名了面试之后，马上就过了。但是我进去之后，我发现我还没有参加比赛。最后才发现，这个协会是有考核制度的。就是大一刚开始会招很多人，但是每隔一两个星期就会出一道题目，C语言或者电路相关的题。

做不出来或者分数低的，直接就被淘汰了。我C语言的功底非常差。所以第二次还是第三次考核的时候，出的题目我完全没有思路，就被淘汰了。那时候我刚上大一，连电脑都没有。一开始学C语言，我是用手机下载了一个C语言的模拟器。在手机上写代码，你想想，手机上敲代码能敲出什么名堂。

所以被淘汰，说实话我一点都不怨。但是回头看，被淘汰这件事反而让我明白了一个道理，就是淘汰不等于出局。只要你自己不走，路就还在。我虽然被淘汰了，但是我一直没有离开协会。因为无限链协会是一个开放的实验室。你就算不是正式的成员，课余时间也可以在里面学习。

里面还有大二大三的学长有问题，你可以随时问。虽然我C语言不行，但是我动手能力还可以的。那会儿我看协会里面有一些大二大三的学长在做一些项目。我就主动帮他们焊板子。然后焊着焊着，就混了个脸熟。后来有个学长对我还不错，开始教我画板子。

一开始就是画一个五一单片机的小系统。我画完之后完全扫不进去代码。然后这个程半天也没搞定，最后还是那个学长帮我找到了问题。但是在这个过程中，我慢慢摸到了门道。如果你现在技术一般进不了什么团队。我的建议是你先别管名分，找一个你能待的地方。

哪怕是先帮别人打打下手，混个脸熟。技术可以慢慢学，但是态度和参与感是你立刻就能拿出来的东西。大一的时候，我报名参加了校级的电车竞赛。但是那会儿磨电、竖电还没学呢，而且单边机也还没学呢。磨电和竖电是要大二才学的，单边机是要大三才学的。

然后电赛是三个人组队。我们组的另一个同学是写单边机软件的。他实力是比较强的，他在大一的时候就加入了复发器。复发器是主要学软件的。然后他虽然不会画板子，但是他稍微能读懂一点单边机最小系统的图。所以我们的分工就是他写软件，我画板子。

我画的第一块板子就是刚刚说的我要单边机的最小系统。然后校赛的。入赛标准就是你要教一个能用的作品。然后我挑了一个最简单的，就是一个带万年力的电子计算器。说实话，此时此刻我对电路的理解还仅限于高中物理学的那点电路知识。怎么画的呢？

我在写字里面，在B站上找的ultimate designer画PCB的视频，然后就照猫画虎，硬画的。真是照猫画虎。那时候我对单边机小系统一知半解。就是照着网上的图一模一样画出来的。

然后画完之后，让我那个队友检查了一下。他帮我看了一下原理图和PCB。然后我去无形电协会用刘顺彤去腐蚀的PCB。然后自己焊的板子。结果焊完之后，竟然能用。就这样我们把作品交上去了。因为本来第一次做东西就是这样，你别怕做的丑，也别怕画的烂。

你先做出来再说。你做的第一个东西本来就不应该完美。然后就说到电子计算机校赛。校赛的题目分几类。控制类的题目是乘控加热。据说每年都是这个题目，而且做的人特别多。也很难拿奖。因为我们是大一的，这道题目说实在的想完成都很难，更何况拿奖了。

然后就是电源类的题目。电源类题目一般都是数控电源，做的人也多。对于大一来说，做完就很难，更何况拿奖。然后我们选择了一道无线通讯类的题目。其实这道题目应该是通信选择。因为我们是学院的学生去做。为什么选这个题目呢？原因很实在，就是我知道做这个题目的人肯定不多。

然后真实的情况也是，全校当时只有一个主做了那道题目，就是我们主。而且这道题目看起来挺难，但是我看了一眼，好像用我熟悉的2.4G模块也可以实现题目的功能。说白了，我们就是找了一个别人不愿意碰，但我刚好有一点点办法的题目。最后我们硬是把功能给出来了。

然后测评的时候是通信学院的老师来测评这道题目。他看了我们的作品，说了一句让我印象很深的话。他说你做的根本不是题目想要的呀，这我怎么给你打分？但当时我们就狡辩嘛，我说按照题目要求我实现的功能呢？你管我用什么方法实现的呢？然后我们就一直在那跟他掰扯。

最后我们竟然拿到了校三灯鸟。而且你要知道，当年电子铁路。

电子信息学院大一参赛的队伍里面只有一个三灯鸟。没有一灯鸟和二灯鸟。这个三灯鸟就是我们组。也正是因为我们组的校赛三灯鸟。我们成了电子信息学院唯一一个大一就获得参加省赛资格的队伍。但是后来参加省赛我们没有拿奖。但是这件事情教会我一个很重要的道理。

就是有的时候选对赛道可能比埋头苦干更重要。你不需要在所有人都在卷的地方比别人强。你只需要在一个没有什么人走的地方。比别人走的远一点。说实话虽然没有拿奖。但是这让我明白的一件事就是。我还是喜欢做硬件的。虽然不能拿奖，但是我比较享受这个过程。

也是从那个时候开始我就不再迷茫了。我知道我以后要干嘛了。说到选赛道，我想插一句当年的实际情况。我不知道大家有没有同感。就是我本科读的是电子信息工程嘛。我们班有40多号人。据我所知，毕业就我一个人做了硬件。我们那一届有2000来号人。

毕业做硬件的也屈指可数。要么搞嵌入式软件，要么搞纯软件去了。后来我读研究生。接了一个比较大的实验室。50多号人，一届十几个人毕业后。算上我，一共就两个做硬件的。那个时代做硬件的人真的太少了。为什么呢？原因很现实。第一，软件需求量大。

那个年代互联网正火。软件赶快需求远远大于硬件。你去招聘会上看，招软件的公司排着队。招硬件的没有几家。而且软件门槛相对来说比较低。一台电脑就能开始写代码。学几个月就能上手。但是硬件呢，需要设备。要买原件，要场地，要人带。起步就劝退了一大批人。

但是反过来想。门槛高也就意味着竞争少。大家都去卷软件了。硬件反而留出了空间。后来我能进大疆，创意做硬件。跟当年选对了这条人少的路。我觉得也是有关系的。回头看，我入门硬件。最重要的其实就三个字。动手做。不是看书看出来的。也不是听课听出来的。

是焊板子焊出来的。是调电路调出来的。是通宵熬夜搞出来的。如果你也想入门硬件。我最大的建议就是。别光看书，动手做。你找一个最简单的项目。哪怕是让一个LED灯亮起来。或者是控制一个流水灯。画图，买原件，焊板子，写代码。调试，整个过程走一遍。

比你啃一个月课本要管用的多。还有一点就是，要找一个圈子。一个人闷头学很容易放弃的。一群人一起搞，相互讨论。相互帮忙，相互较劲。才能坚持下来。说到圈子，我想多说两句。就是大学里面学硬件。我强烈建议你一定要加入一个实验室。或者科协。

或者什么电子协会之类的。哪怕学校没有专门的科协。很多学校也有公共的实验室可以申请。为什么呢？有两个原因。第一个是，做硬件真的很烧钱。试波器，焊台，电源。电子元件，PCB打样。哪一样不要钱？你自己买一个月生活费，根本都不够。

实验室有公共资源。你可以免费用。这一下就帮你省了不少钱。第二个，你得有一个圈子。硬件这个东西，一个人闷头搞，真的搞不了。你遇到问题，没人问呢。现在有AI可能好一点。但是有的时候AI不一定能解决。很多硬件上遇到的问题。而且最重要的是。

你做出来的东西要有人分享。你如果没人分享的话。长时间就觉得没劲了。但是你能带学弟。这样相互讨论，进步一定比。你一个人搞快的多。我当时就是在无线内协会找到了一群。一起搞硬件的人，这些人。后来有人去了华为，有人去了。大奖，也有人去了阿里。

也有自己创业的。但是，这些人就是一群在实验室。焊板子焊到半夜的普通学生。好了，这就是我。入门硬件的起点。你不需要一开始就很厉害。你只需要先开始做。如果你也想入门硬件，或者。正在入门硬件的路上，关注我。下一期，咱们聊点实在的。

入门硬件，到底该。学哪些东西。提前说一句，别一上来就。啃磨电，真的会劝退的。我是硬件何工，一个还在跟硬件。死磕的工程师，下期我们再见。
