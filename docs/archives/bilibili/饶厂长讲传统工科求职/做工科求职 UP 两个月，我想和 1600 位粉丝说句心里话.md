# 做工科求职 UP 两个月，我想和 1600 位粉丝说句心里话

## 来源

https://www.bilibili.com/video/BV1iNMa6BEcz

作者：饶厂长讲传统工科求职

## 原文案

做自媒体两个月了，给大家汇报一下，分享一下

## 口播转录

从5月中旬到现在，我在B站做工科求职相关的内容已经快两个月了，非常感谢各位粉丝朋友对我的认可，非常感谢，也非常感谢找我咨询的朋友们，你们的关注和互动，还有一对一的交流给我非常大的鼓励，让我能够坚持的做下来。今天这期视频，我给各位粉丝朋友做个汇报，也聊一聊关于这个账号的想法，截止到今天，视频播放量已经接近10万，评论近千条，粉丝也从500多涨到了1600多，虽然不是什么特别厉害的成绩，但我想这个成绩也证明了我做的内容确实是被人需要和认可。

截止到今天，我已经为23位朋友做了一对一的付费咨询，虽然也不算什么特别了不起的成绩。但我想这实实在在也证明了每个人都有独特的需求，我的咨询是分段付费的，先付40%预付，交流完认为有用，再付剩下的60%，目前咨询的满意度是100%，这也给我非常大的鼓励，感谢大家的信任和认可。

这些朋友里面有在校学生，也有工作两三年遇到困境的工程师，甚至还有工作的15年以上的前辈，在和大家的交流中。我自己也有很多收获，那7月份呢，我也是正式加入了B站的UP主的扶持计划，现在向万分冲刺努力中。接下来说说我做这个账号的初衷，我这个账号其实三年前就发过一些内容，主要是展示一下自己的小项目，通过这些项目呢，去做一些商业上的合作，或者是找一些这个合适的工作。

但是今年呢，我可能工作不太饱和，我在这个过程中多了非常多的思考的事。也把以前的经历做了一下复盘，我发现在刚毕业的时候，由于信息差做了非常多的错误的判断，导致我那个时段人生的决策质量非常非常的差，于是我就想把这些信息差通过视频的方式发出来，能够帮助正在经历我当时困境的这些年轻人，同时也靠一对一的咨询做一些变现的动作。

我现在已经拍过的这些视频，包括。未来将不断更新的那些视频，其实内核就三个点，第一是工科要靠实践积累能力，第二是一定要了解工程师和公司的关系，了解公司和社会的关系，第三个点是不同领域的工程技术有深刻的相互影响和联系，但是这些非常简短的道理，没有办法帮助任何人，于是我就做视频来从不同的角度，不同的切入点来重复说这些话题。

比如说。我讲面试相关的，其实就是讲工程师和公司关系的延伸，比如说我讲求职的岗位那些方向，行业的各种不同的方向，其实讲的就是岗位和公司的关系，公司和行业的关系，行业和社会的关系，比如说我在讲一些这个建议大家去提高这个相邻的技术认知，其实就是讲不同领域的深刻联系，其实讲来讲去，我那么多视频都是讲这三个内容，所以我的内容从现在来看。

可能永远不会枯竭，因为我的核心内容永远还是这些点，只是说切入点是无穷无尽，每个人遇到的问题无穷无尽，所以我的内容只要愿意跟，我就可以一直跟下去，我也非常欢迎网友们给我私信或者评论，说说你们的建议和非常想看到的一些切入点或者内容，那么点赞高的我可以优先安排成视频。

那么我会把一些关系的一些业内做得不错的一些初创公司或者中型规模的公司，那么可能会帮他们做一些招聘相关的工作，我会把招聘的岗位通过视频的方式进行拆解，比如说某某岗位他是做什么的，他在什么产品里面发挥什么作用，他的工作流程是怎么样的，他的价值上限是怎么样，然后把这些介绍给大家，并且通过邮箱或者B站的网友投过来的简历，我把这些简历进行一些收集。

那么能够通过我的简历评估。和我们简短面试之后合适的候选人我会推荐给企业，一方面呢，这是扩展我的变现渠道，另外一方面，我也是在做这个视频过程中也能帮助正在求职或者在学校的一些朋友能够提前了解到这些真实的岗位的工作内容，另外呢，我会尝试把我的经历整理一下，做成视频分享给大家，一方面让网友们能通过我的经历增强一些自己的信心。

另外一方面呢，也能印证我视频里面其他的那些内容，并不只是说说而已，这些每个内容，每个视频背后都是一个真实的坑，都是一段真实的经历。

最后，希望看到我视频的小伙伴都求职顺利，工作顺行，关注我，带你看清传统工科求职的底层原理。
