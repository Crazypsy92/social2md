# 云端磁盘保护机制

## 默认阈值

| 项目 | 默认值 |
|---|---:|
| 暂停阈值 | 95% |
| 恢复阈值 | 90% |
| 最低剩余空间 | 1 GiB |
| 下载期间检查间隔 | 2 秒 |
| 默认批量大小 | 5 个作品 |
| 下载并发 | 1 个作品任务 |
| 转录并发 | 1 个视频 |

## 监控范围

监控项目工作区、视频目录、Markdown 输出目录、状态目录、系统临时目录和 Hugging Face 模型缓存目录。按设备号去重，避免同一文件系统被重复计算。可用时同时检查 inode 使用率。

## 暂停和恢复

达到 95%、剩余空间低于 1 GiB、inode 达到暂停阈值，或转录预估临时空间不足时，程序停止启动新作品。下载期间会轮询磁盘；触发保护时取消当前下载任务，只有校验失败的半成品视频才会清理，完整视频和 Markdown 保留。

恢复条件为所有受监控文件系统使用率低于 90%，且剩余空间满足最低保护值。程序不会在同一个任务中无限等待空间恢复；退出后重新启动相同命令即可恢复。

## 删除条件

只有以下条件全部满足才会删除视频：

1. 视频可被 ffprobe 读取且时长有效。
2. 转录过程没有异常。
3. Markdown 已原子写入正式文件。
4. Markdown 包含非空的语音转录或画面文字。
5. Whisper 质量指标未触发低置信度复核。

低置信度作品会保留原视频并标记为 REVIEW_REQUIRED。空转录、异常、损坏视频和写入失败均保留原视频。
